# E-commerce-website-for-clothing
WardrobeX is a modern React-powered clothing e-commerce site featuring sleek UI, category-based navigation, and smooth user authentication.


Step 1: Download & Install Node.js
Go to https://nodejs.org and download the LTS version.

Step 2: Verify Installation
Open terminal or command prompt:
node -v and npm -v

Step 3: Install Git (if needed)
Download from https://git-scm.com

Step 4: Clone Your Project Repository
git clone https://github.com/your-username/wardrobex.git
cd wardrobex

Step 5: Install Dependencies
npm install

Step 6: Start the React App
npm start

Step 7: Open in Browser
Visit http://localhost:3000
